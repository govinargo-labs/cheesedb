# Contributing

Issues and pull requests are welcome. Run `go test ./...` before opening a
pull request; a change to behaviour needs a test that shows it.

## AI-assisted contributions

Welcome — cheesedb was itself built with Claude. Two conditions:

- **Say so in the pull request**, and keep any `Co-Authored-By` trailer your
  tool adds.
- **Only submit what you understand and have run.** You should be able to
  explain every change and answer review questions about it. Security reports
  in particular must be reproduced by you, not just described by a model; see
  [THREAT_MODEL.md](THREAT_MODEL.md) for what is in scope.
